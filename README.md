# Anbar CS Student Activities Garden 🌿

Arabic environmental educational website for the **Student Activities Garden** at the **College of Computer Science and Information Technology – University of Anbar**.

This project presents the garden as an educational and interactive digital experience, showing its plants, rehabilitation stages, project gallery, location, and participating student team.

---

## 🌱 About the Project

**ميدان النشاطات الطلابية** is an environmental and educational student project at the College of Computer Science and Information Technology, University of Anbar.

The website aims to document the garden project digitally and make its content easy to explore through a clean Arabic interface. It includes plant information, project photos, a location map, a rehabilitation video, and the names of the participating students.

The project was designed and developed by:

* **Bilal Zamil Ahmed**
* **Malak Mazen Yousif**

---

## ✨ Features

* Arabic RTL interface
* Responsive design for desktop and mobile
* Interactive navigation between sections
* Home page with project hero image
* Embedded video showing rehabilitation stages
* Google Maps location embed
* Plant encyclopedia with detailed plant cards
* Modal view for plant details
* Project photo gallery
* Image lightbox with next/previous controls
* Participants section
* About section describing the project
* Clean UI using Tailwind CSS
* Icons powered by Lucide Icons

---

## 📌 Website Sections

### 🏠 Home

Includes the main project image, welcome message, rehabilitation video, and project location map.

### 🌿 Plants

An interactive plant encyclopedia containing many plants used in the garden. Each plant includes:

* Arabic name
* Scientific name
* Category
* General description
* Environmental impact
* Plant details such as height, season, temperature, and type

### 🖼️ Gallery

A photo gallery documenting the project stages and garden views, with a fullscreen lightbox viewer.

### 👥 Participants

A section listing the students who participated in the project.

### ℹ️ About

A short description of the project, its environmental value, and its educational purpose.

## 🚀 How to Run Locally

1. Clone the repository:

```bash

```

2. Open the project folder:

```bash

```

3. Open `index.html` in your browser.

No backend or installation is required.
